# 🏨 Modelo MauiAppHotel  
Componentes de Interface • BindingContext • Layout

Este projeto foi desenvolvido como parte da **Agenda 13 – Programação Mobile I**, no Curso Técnico em Desenvolvimento de Sistemas (CETEC / CPS).  
O objetivo desta agenda é explorar componentes visuais do .NET MAUI, incorporar imagens, utilizar controles básicos da interface gráfica e criar uma tela adicional denominada **Sobre**.

---

## 🇧🇷 Descrição (Português)

O aplicativo **MauiAppHotel** é uma versão inicial do projeto AppHotel, focada na construção da interface gráfica e no uso de diversos componentes do .NET MAUI.

### ✔️ Funcionalidades implementadas
- Construção do layout base apresentado no material da Agenda 13  
- Uso de componentes visuais como:
  - `Label`
  - `Entry`
  - `DatePicker`
  - `Picker`
  - `Stepper`
  - `Button`
  - `StackLayout` e `Grid`
- Organização da interface seguindo boas práticas do XAML
- Personalização visual do layout
- Criação da página **Sobre**, contendo:
  - Nome do desenvolvedor
  - Ano de desenvolvimento
  - Informações complementares
- Navegação entre páginas utilizando **AppShell**

### ✔️ Tecnologias utilizadas
- .NET MAUI  
- .NET 7 / 8  
- Visual Studio 2022  

---

## 🇬🇧 Description (English)

The **MauiAppHotel** project is the initial stage of the AppHotel application, developed for **Agenda 13 – Mobile Programming I**.  
This version focuses on layout construction, UI components and basic page navigation using .NET MAUI.

### ✔️ Implemented features
- Development of the base layout defined in the course material  
- Use of essential UI components such as:
  - `Label`
  - `Entry`
  - `DatePicker`
  - `Picker`
  - `Stepper`
  - `Button`
  - `StackLayout` and `Grid`
- Customized and organized visual structure with XAML
- Added an **About** page containing:
  - Developer name
  - Year of development
  - Additional project details
- Navigation between pages via **AppShell**

### ✔️ Technologies used
- .NET MAUI  
- .NET 7 / 8  
- Visual Studio 2022
